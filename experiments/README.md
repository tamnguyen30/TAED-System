# Experiment Entry Points

This directory contains simplified entry points for reproducing TAED experiments.

## Planned Workflow

1. Prepare datasets following `data/README.md`.
2. Configure model settings.
3. Train baseline and TAED components.
4. Run adversarial robustness evaluation.
5. Generate evaluation results and figures.

The scripts in this directory serve as reproducibility wrappers around the core implementation in `src/`.
