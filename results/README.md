# Historical evaluation outputs

These files are preserved from earlier experiments. Their existence does not establish that they use the revised manuscript's configuration or identical datasets.

For every result cited, retain the source commit, command, configuration, checkpoint hashes, dataset/split identity, sample counts, and metric denominator. Some plotting scripts contain embedded values rather than reading evaluation output; regenerating those figures does not rerun the experiment.

The cleanup does not alter recorded results, replace values with manuscript targets, or claim that historical outputs reproduce the current paper.
