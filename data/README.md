# Dataset Information

This directory documents the datasets and preprocessing procedures used in TAED experiments.

## Dataset Sources

The experiments use publicly available phishing and legitimate email datasets. Dataset sources, preprocessing steps, and filtering procedures are documented to support reproducibility.

## Data Preparation

The preprocessing pipeline includes:

- data cleaning and normalization
- label processing
- feature preparation
- adversarial example generation for robustness evaluation

Raw datasets are not included when redistribution restrictions apply. Users should obtain the original datasets from their respective sources and follow the documented preparation steps.

## Reproducibility

Dataset construction details and evaluation settings are described in the paper and accompanying documentation.
